# 文化艺术图

一册中秋小图。**夏川 · 澪** 为主题角色的插画与表情。

打开 [index.html](index.html) 可看图册（离线单文件，无外部依赖，手机浏览器亦可）。

---

## 目录

```
art/
├── index.html    图册页（浏览器打开）
├── images/       原图（8 幅）
├── thumbs/       预览图（1100px 内，供网页与 README 引用）
└── README.md     本文件
```

## 关于她

**夏川 · 澪**（Natsukawa Mio）—— 本册插画的主题角色，也是本项目的形象。

温柔、腼腆、认真，容易害羞，有点笨拙，但总是努力着。
喜欢甜食、安静的地方、绘画，和可爱的东西。

角色页与中秋小站：**[xiaozayu.top/夏川.澪](https://xiaozayu.top/%E5%A4%8F%E5%B7%9D.%E6%BE%AA/)**　（作者的个人创作站点）
