# 退出码与输出约定

设计目标：**调用方零文本解析**。

---

## 一、退出码

| 码 | 含义 | 典型场景 |
|---|---|---|
| **0** | 成功 / 判定为真 | 命令正常完成；`in-group` 判定在群 |
| **1** | 判定为假 | `in-group` 不在群；`group-name` 群名未找到 |
| **2** | 用法错误 | 缺参数、未知命令、未知选项、号码格式错、非法 `--space` |
| **3** | 环境错误 | 非 root、未发现 QQ 数据目录 |
| **4** | 数据不可用 | 解密失败、字段缺失、记录不存在 |

### 实测矩阵（12/12 通过）

```
in-group 在群          0
in-group 已退群        1
in-group 假群          1
in-group 缺参数        2
in-group 非数字        2
未知命令               2
未知选项               2
非法 --space           2
group-name 不在群      1
user 不存在            4
help                   0
version                0
```

### 使用要点

```
· 判定类命令（in-group / group-name）用 0/1 分支
· 参数错误(2) 与 环境错误(3) 应分别提示，不要混为"失败"
· 数据不可用(4) 不等于"判定为假"，业务上要区分
```

## 二、stdout / stderr 分离

```
stdout  → 纯结果（可被 $(...) 直接捕获）
stderr  → 注释性内容（以 "#" 开头）+ 错误信息
```

例：

```bash
$ zql in-group 123456789
true                                  # stdout
# 示例群名称(3号缸)…  [主空间]   # stderr

NAME=$($ zql in-group 123456789 2>/dev/null)    # 只拿到 true
```

错误信息一律走 stderr，前缀 `[错误]`。

---

## 三、输出形态约定

| 形态 | 命令 | 说明 |
|---|---|---|
| **单行纯值** | self-qq, self-name, self-sign, self-level, group-count, group-title, group-level | `$(...)` 直接捕获 |
| **true/false** | in-group | 判定类，配合退出码 |
| **制表符分隔** | groups, group-members, msgs | 用 `IFS=$'\t'` 或 `awk -F'\t'` 解析 |
| **多行键值** | self, user | `键: 值` 形式，人工可读 |
| **JSON** | 加 `--json` 时 | 稳定契约，字段只增不减 |

制表符解析示例：

```bash
$ZQL groups 2>/dev/null | while IFS='	' read -r code name members; do
    echo "群 $code = $name ($members)"
done
```

## 四、JSON 契约（稳定字段）

### in-group
```json
{ "group": "123456789", "in_group": true, "name": "…", "space": "主空间" }
```

### self / user
```json
{ "space": "主空间", "uid": "u_…", "qq": "100000001",
  "name": "…", "sign": "…", "gender": "女" }
```

### groups
```json
[ { "code": "123456799", "name": "示例群名称C", "members": 2751 } ]
```

### group-members / group-title
```json
{ "qq": "100000001", "uid": "u_…", "name": "…", "card": "…",
  "title": "示例头衔", "level": 0, "points": 0,
  "admin": false, "join_ts": 1782129393 }
```

### msgs
```json
[ { "ts": 1791129130, "qq": "…", "nick": "…", "kind": "text", "text": "…" } ]
```

---

## 五、字符编码

```
· 全部输出为 UTF-8
· 中文、emoji 原样输出（如 示例昵称）
· 终端不支持 emoji 时可能显示为方块，但数据与捕获结果不受影响
```

---

## 六、稳定性承诺

```
· 命令名、选项名、退出码语义：本版内不变
· JSON 字段：只增不减（新增字段不影响既有解析）
· 单值命令的输出格式（单行纯值）：不变
· 若未来必须变更，将提升主版本号并在文档中标注迁移方式
```
