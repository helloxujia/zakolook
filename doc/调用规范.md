# 调用规范（权威）

本规范经真机实测验证，脚本可直接照此编写。
（v1.5.1 起新增 QQ 频道一节，见第十节）

---

## 一、环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| 架构 | arm64 | 二进制为 aarch64 静态链接 |
| 系统 | Android 7.0+ | 依赖 `os.ReadDir` 等基础能力 |
| 权限 | **root** | 需读 `/data/user/<空间>/com.tencent.mobileqq` |
| 前提 | QQ 已安装并登录过 | 否则无数据目录 |
| 存储 | `/data` 下可写 | 缓存目录默认 `/data/local/tmp/zql_data` |

```
注意：/sdcard 为 fuse 挂载，不可直接执行二进制。
     必须先把 zql 复制到 /data 下（如 /data/local/tmp/）。
```

## 二、部署

```bash
# 推荐路径
cp bin/zql /data/local/tmp/zql
chmod 755 /data/local/tmp/zql

# 自检（应输出账号空间列表）
su -c "/data/local/tmp/zql status"
```

脚本中建议统一变量：

```bash
ZQL=/data/local/tmp/zql
# 若脚本本身已以 root 运行，可直接调用；否则套 su -c
run_zql() { su -c "$ZQL $*"; }
```

## 三、调用约定

### 3.1 结果捕获

单值命令输出**单行纯值**，可直接捕获：

```bash
MY_QQ=$($ZQL self-qq)          # → 100000001
MY_NAME=$($ZQL self-name)      # → 示例昵称
CNT=$($ZQL group-count)        # → 85
```

### 3.2 判定用退出码，不解析文本

```bash
if $ZQL in-group "$GID" >/dev/null 2>&1; then
    echo "在群"
else
    case $? in
        1) echo "不在群" ;;
        2) echo "参数错误" ;;
        3) echo "环境错误（需 root）" ;;
        4) echo "数据不可用" ;;
    esac
fi
```

### 3.3 提示信息走 stderr

工具把注释性内容（`#` 开头）输出到 **stderr**，
因此 `$(...)` 捕获到的永远是纯结果：

```bash
NAME=$($ZQL self-name 2>/dev/null)   # 即使有提示，也不污染结果
```

### 3.4 静默模式

```bash
$ZQL groups --quiet > list.txt       # 不带 "# 共 N 个群" 尾注
```

### 3.5 对象定位规则（群 / 频道通用）

**判定与详情类命令**接受三种定位方式，按此优先级匹配：

| 方式 | 例 | 说明 |
|---|---|---|
| ID（数字） | `1000000000000001` | **脚本首选** —— 不受改名、emoji、空格影响 |
| 短名 | `sample-channel` | 人读友好；但不是每个频道都有 |
| 名称 | `示例频道` | 最脆（含 emoji/空格，必须加引号） |

```bash
$ZQL in-guild 1000000000000001   # → true
$ZQL in-guild sample-channel        # → true（同一条）
$ZQL in-guild 示例频道      # → true（同一条）
```

> 列表类输出一律 **制表符分隔**，用 `awk -F'\t'` 切；不要用空格切（名称里带空格）。

## 四、结构化输出

需要程序化处理时用 `--json`：

```bash
$ZQL in-group 123456789 --json | jq -r '.in_group'
$ZQL groups --json | jq -r '.[] | "\(.code)\t\(.name)\t\(.members)"'
$ZQL group-members 123456789 --json | jq -r '.[] | select(.admin) | .name'
$ZQL guild-list --json | jq -r '.joined[] | "\(.id)\t\(.name)"'
```

JSON 字段为稳定契约，不会随版本删除（只增不减）。

## 五、多账号空间

```
主空间      /data/user/0/com.tencent.mobileqq
分身(u998)  /data/user/998/...
分身(u999)  /data/user/999/...
```

同一空间内还可能并存**多个库目录**（该空间登录过多个 QQ，旧目录会保留）：

```bash
$ZQL accounts                 # 先看有哪些账号、哪个是在线的
$ZQL --qq <QQ号> self-name     # 再定向到指定账号
```

`accounts` 的第四列给的就是状态：**活动** = 当前在线账户（库文件最近写入者），
**历史** = 旧目录。**不要拿历史目录的号去做判定**。

默认遍历全部空间：
- `in-group` / `group-name` 等判定命令：**任一处命中即为真**
- `self` / `groups` 等取值命令：**默认取当前活动账号**（不是目录顺序的第一个）

限定空间：

```bash
$ZQL self --space main        # 只看主空间
$ZQL groups --space dual      # 只看分身
$ZQL guild-list --space main  # 频道同理
```

限定账号（与限定空间可叠加）：

```bash
$ZQL --qq 100000002 self-name
$ZQL --qq 100000002 in-group 123456789
$ZQL --qq 100000002 msgs 123456789 --n 10
```

> 典型用法：**先 `accounts` 确认哪个是在线账户，再 `--qq` 定向** ——
> 这是应用分身 / 多账号场景下取到正确账号的唯一稳妥做法。

> 频道只有"用过频道功能"的账号空间才有数据。空壳库会明确报
> `该账号空间没有频道数据（频道库为空壳 —— 此账号从未使用过 QQ 频道）`（退出码 4）。

## 六、缓存与时效

```
首次调用某库 → 解密并缓存（profile/group 约 1s；nt_msg 632MB 约 6.7s）
后续调用     → 校验源库 (size, mtime)，未变则复用（约 50ms）

缓存位置：/data/local/tmp/zql_data/cache/
强制刷新：$ZQL <命令> --fresh
```

**注意**：QQ 更新数据后（如新收消息、新入群），mtime 变化会自动触发重解密，
无需手动干预。

## 七、错误处理建议

```bash
check_env() {
    $ZQL status >/dev/null 2>&1 || {
        case $? in
            3) echo "环境错误：请确认已 root，且 QQ 已登录过" >&2 ;;
            *) echo "未知错误" >&2 ;;
        esac
        return 1
    }
}
```

对 `in-group` 之外的命令，建议区分「数据不可用(4)」与「判定为假(1)」：

```bash
NAME=$($ZQL group-name "$GID" 2>/dev/null); rc=$?
if [ $rc -eq 0 ]; then
    echo "群名: $NAME"
elif [ $rc -eq 1 ]; then
    echo "不在该群"
else
    echo "查询异常（退出码 $rc）"
fi
```

## 八、性能建议

```
· 批量查询同一数据时，先跑一次触发解密，后续调用走缓存
· 循环内调用注意合并（如用 groups --json 一次取全量，而非逐个 group-name）
· 不要加 --fresh（会强制重解密）
```

批量示例：

```bash
# 一次取全部群，本地过滤（优于逐个调用）
$ZQL groups --json | jq -r --arg g "$TARGET" '.[] | select(.code==$g) | .name'
```

## 九、最小可用模板

```bash
#!/system/bin/sh
set -u

ZQL=/data/local/tmp/zql

# 1) 环境自检
$ZQL status >/dev/null 2>&1 || { echo "环境未就绪" >&2; exit 3; }

# 2) 取本人信息
MY_QQ=$($ZQL self-qq 2>/dev/null)
MY_NAME=$($ZQL self-name 2>/dev/null)
echo "本人: $MY_QQ ($MY_NAME)"

# 3) 群验证
for g in "$@"; do
    if $ZQL in-group "$g" >/dev/null 2>&1; then
        echo "$g: 在群 — $($ZQL group-name "$g" 2>/dev/null)"
    else
        echo "$g: 不在群"
    fi
done
```

## 十、QQ 频道调用规范（v1.5.1 新增）

### 10.1 命令一览

```
guild-list [--all]                我加入的频道（ID \t 名称）
guild-info <ID|短名|名称>          频道详情
guild-channels <ID|短名|名称>      子频道列表（按分组）
guild-roles <ID|短名|名称>         身份组列表
in-guild <ID|短名|名称>            是否已加入 → true/false（退出码 0/1）
guild-msgs <ID|短名|名称> [--kw 词] [--n N]   频道消息（实验性，需 --exp）
```

### 10.2 `guild-list`

输出 `频道ID \t 名称`，一行一个；`--all` 追加"仅浏览过、未加入"的（第三列标 `(未加入)`）。
默认只列**已加入**——判据来自另一张权威表，已排除退频道残留。

```bash
$ZQL guild-list
# 1000000000000004	示例频道A
# 1000000000000003	示例频道B
# ...
# （stderr）# 我加入的频道 42 个（另有 9 个仅浏览过）[主空间]

CNT=$($ZQL guild-list 2>/dev/null | wc -l)           # → 42
```

**反查 ID（脚本里最常用）**：

```bash
GID=$($ZQL guild-list 2>/dev/null | awk -F'\t' '$2=="示例频道"{print $1; exit}')
[ -n "$GID" ] || { echo "找不到该频道" >&2; exit 1; }
```

### 10.3 `guild-info`

```
频道ID : 1000000000000001
名称   : 示例频道
短名   : sample-channel
已加入 : true
子频道 : 13 个
身份组 : 32 个
成员数 : ≥10830（该频道全员身份组人数）
我的身份组: LV.13
```

固定字段用 `awk -F' : '` 取：

```bash
NAME=$($ZQL guild-info "$GID" 2>/dev/null | awk -F' : ' '/^名称/{print $2}')
SHORT=$($ZQL guild-info "$GID" 2>/dev/null | awk -F' : ' '/^短名/{print $2}')
```

### 10.4 `guild-channels`

按分组输出，子频道行是 `ID \t 名称 \t 类型`：

```
[讨论组]
200000002	使用交流 | 闲聊杂谈💤	文字
13105645	小智の打卡	文字
[帖子广场]
200000001	📢入群必看	帖子
[未分组]
200000003	日程子频道	日程
```

分组标题行是 `[组名]`（无制表符，1 个字段），数据行是 `ID \t 名称 \t 类型`（3 个字段），
区分只需看 `NF`：

```bash
$ZQL guild-channels "$GID" 2>/dev/null | awk -F'\t' 'NF>=3{print $1, $2}'
```

类型标签：`文字 / 语音 / 帖子 / 直播 / 应用 / 签到 / 日程 / AI`
（据本机数据归纳，未在官方文档确认；若遇未知值原样输出 `typeN`）

```bash
# 只取子频道 ID 列表
$ZQL guild-channels "$GID" 2>/dev/null | awk -F'\t' 'NF>=3{print $1}'

# 找某个子频道
$ZQL guild-channels "$GID" 2>/dev/null | awk -F'\t' '$2 ~ /Bug反馈/ {print $1}'
```

### 10.5 `guild-roles`

`ID \t 名称 \t [标签] \t [颜色] \t N人`。
等级身份组显示为 `LV.n`（取自 `description_`），颜色为 `#RRGGBB`。

```bash
$ZQL guild-roles "$GID"
# 2	超级管理员	管理员	#FF862E	12人
# 4	频道主	频道主	#FF3F32	1人
# 11	LV.1	#000000	10830人

# 取我在该频道的等级身份组
$ZQL guild-info "$GID" 2>/dev/null | awk -F' : ' '/^我的身份组/{print $2}'   # → LV.13
```

### 10.6 `in-guild`

```bash
$ZQL in-guild 1000000000000002        # → true    exit 0
$ZQL in-guild 1000000000000007         # → false   exit 1（仅浏览过，未加入）
$ZQL in-guild sample-channel              # → true
```

脚本判定模板（stdout 干净，退出码权威）：

```bash
if $ZQL in-guild "$GID" >/dev/null 2>&1; then
    echo "已加入"
else
    case $? in
        1) echo "未加入" ;;
        4) echo "数据不可用" ;;
    esac
fi
```

### 10.7 `guild-msgs`（实验性）

注意：需显式加 `--exp`，否则直接报用法错。
短板：`guild_msg.db` 有部分页只存在于 `-wal`，而 SQLCipher 的 WAL 帧加密方式与主库页不同
（尚未解出），**结果可能取不全**。范围强制限定在本人已加入的频道。

```bash
$ZQL guild-msgs 1000000000000001 --exp --n 6
# 10-06 09:54	示例用户	示例消息内容一
# 09-26 05:50	示例用户	示例消息内容二
# （stderr）# 注意：guild-msgs 为实验性功能，结果可能取不全（...）

$ZQL guild-msgs sample-channel --exp --kw root --n 20
```

### 10.8 默认频道（`ZQL_GUILD`）

频道类命令（`guild-info` / `guild-channels` / `guild-roles` / `in-guild` / `guild-msgs`）
都支持用环境变量设「默认频道」，设过之后可省略参数：

```bash
export ZQL_GUILD=1000000000000001      # 也接受短名 sample-channel / 名称
$ZQL guild-info                        # 等价于 zql guild-info 1000000000000001
$ZQL guild-channels
$ZQL in-guild                          # → true（退出码 0/1 语义不变）
$ZQL guild-msgs --exp --n 20           # 选项照给，频道位省略
```

规则：

- **命令行参数优先** —— 显式给了频道就不看环境变量
- 环境变量与参数**同样接受** ID / 短名 / 名称
- 两者都没有 → 报用法错（退出码 2），并提示如何设置 `ZQL_GUILD`
- `guild-list` 不吃频道参数，不受影响

脚本里最常见就是开头钉一次：

```sh
#!/system/bin/sh
set -u
ZQL=/data/local/tmp/zql
export ZQL_GUILD=1000000000000001

su -c "$ZQL guild-info"
su -c "$ZQL guild-channels" 2>/dev/null | awk -F'\t' 'NF>=3{print $1, $2}'
```

> 注意：`su -c` 默认不会继承外层环境。若要带进去，用
> `su -c "ZQL_GUILD=$ZQL_GUILD $ZQL guild-info"`，或在同一 `su -c` 里 `export`。

### 10.9 频道脚本模板

```bash
#!/system/bin/sh
set -u
ZQL=/data/local/tmp/zql
GID=1000000000000001            # ← 固定查询该频道（脚本首选硬编码 ID）

# 环境
$ZQL status >/dev/null 2>&1 || { echo "环境未就绪" >&2; exit 3; }

# 是否已加入
if ! $ZQL in-guild "$GID" >/dev/null 2>&1; then
    echo "未加入该频道" >&2; exit 1
fi

# 基本信息
$ZQL guild-info "$GID" 2>/dev/null

# 子频道清单（ID + 名称）
$ZQL guild-channels "$GID" 2>/dev/null | awk -F'\t' 'NF>=3{printf "  %s\t%s\n",$1,$2}'
```

批量固定多个频道：

```bash
for GID in 1000000000000001 1000000000000002 1000000000000002; do
    $ZQL guild-info "$GID" 2>/dev/null \
      | awk -F' : ' -v g="$GID" '/^名称/{printf "%s\t%s\n", g, $2}'
done
```
